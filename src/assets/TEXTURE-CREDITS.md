# Paper textures

## Paper 3 (active)

Creator: Atle Mo.

Source: https://www.transparenttextures.com/paper-3.html

Downloaded image: https://www.transparenttextures.com/patterns/paper-3.png

The PNG is used unchanged at its native 276 x 276 pixel tile size, with CSS
multiply blending on the paper sheets.

## Cream Paper (quiet content panels)

Creator: Devin Holmes.

Original pattern: https://www.toptal.com/designers/subtlepatterns/cream-paper/

Transparent version: https://www.transparenttextures.com/cream-paper.html

Downloaded image: https://www.transparenttextures.com/patterns/cream-paper.png

The PNG is used unchanged at its native 158 x 144 pixel tile size. CSS soft-light
blending gives cards and filter panels a quieter, lighter grain than the main
sheet. Inputs, image placeholders, and plain light utility surfaces stay clean.
